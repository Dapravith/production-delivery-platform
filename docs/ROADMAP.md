# Twelve-week DevOps roadmap

1. Build and test both WebFlux services locally.
2. Configure Keycloak scopes and verify allowed and denied API requests.
3. Build non-root images and inspect their layers and runtime users.
4. Run Jenkins pull-request quality gates.
5. Push immutable SHA-tagged images to a registry.
6. Deploy the Helm chart to kind and test probes and rollouts.
7. Move environment values to a separate GitOps repository.
8. Configure Argo CD reconciliation and test drift self-healing.
9. Install Prometheus and build latency, traffic, error, and saturation panels.
10. Collect structured application logs in Loki and correlate them by trace ID.
11. Add SLO alerts, a Telegram routing policy, and an incident runbook.
12. Run a failed-release exercise and demonstrate rollback plus recovery evidence.

Every week should finish with evidence: a commit, test output, screenshot, dashboard, alert, or short runbook entry.
